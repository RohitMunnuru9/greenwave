See the traffic

The junction camera is split into approach regions. Vehicles that stop for a second or more count as queued.

feed off
model: loading0 fps0 seen · 0 queued—
source
regions count

Detection: TensorFlow.js COCO-SSD in the browser. Each vehicle is tracked between frames; if it moves less than half a car length per second it is queued. Ambulance: a vehicle whose body shows the red cross or light bar (5 to 22% red with some white) for four frames in a row, or the test button. The pilot replaces this rule with a trained ambulance class and siren detection. Pick the region layout that matches the clip: a top-down junction uses four regions, a highway clip one or two.
